# Getting help

This is a personal open-source project. There is no commercial support, and no
response-time guarantee.

| I want to… | Go to |
| --- | --- |
| Understand what this does | [README](README.md) |
| Understand how it is built | [AGENTS.md](AGENTS.md) |
| Run it locally | [Quick start](README.md#quick-start) |
| See what changed between versions | [CHANGELOG](CHANGELOG.md) |
| Report a bug | [Open an issue](https://github.com/mischapogr/geonames-service/issues) |
| Propose a change | [Open an issue](https://github.com/mischapogr/geonames-service/issues/new/choose) first, then a pull request |
| Report a vulnerability | [SECURITY.md](SECURITY.md), not a public issue |

Before opening an issue, please include the request URL (with any API key
removed), the full response body, and which dataset you imported
(`cities15000`, `allCountries`, with or without alternate names). Most search
surprises come down to the dataset.
